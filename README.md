## 🌐 About This Repository (`portfolio-with-agent`)

This repository powers **[sanjaygl.vercel.app](https://sanjaygl.vercel.app)**, an interactive, full-stack developer portfolio and technical operating system.

### Key Architectural Highlights
1. **Sanjay AIOS v2.6 Neural Co-Pilot**:
   - Integrated floating conversational AI agent with real-time portfolio reasoning.
   - Dual-tier architecture: Instant client-side RAG knowledge graph (`js/agentKnowledge.js`) with automatic fallback to serverless backend endpoints (`/api/agent`).
   - Session continuity, context-aware project recommendations, and instant query answering.
2. **Defensive Security & Encryption**:
   - Contact form submissions are encrypted at rest using Fernet AES-128 CBC symmetric encryption (`cryptography`).
   - Anti-spam honeypot verification and IP-based sliding-window rate limiting.
   - Strict security response headers: Content Security Policy (CSP), HTTP Strict Transport Security (HSTS), X-Frame-Options, and X-Content-Type-Options.
3. **Consolidated Data Layer**:
   - Single-source datasets in `data/identity.json` and `data/projects.json`.
   - Unified SQLAlchemy ORM supporting both local SQLite (`database/portfolio.db`) and production cloud MySQL databases with SSL/TLS enforcement.
4. **Clean Redesign 2026 UI/UX**:
   - Ultra-premium glassmorphic dark theme, responsive typography, and smooth micro-interactions.
   - Standardized canonical URLs, Schema.org `Person` & `SoftwareSourceCode` JSON-LD structured metadata, and XML sitemap for SEO discovery.

## 💻 Local Quickstart

### Prerequisites
- **Python 3.10+** (Tested on Python 3.12)
- **Git**
- **pip** package manager

### Setup Steps

1. **Clone the repository**:
   ```bash
   git clone https://github.com/SanjayGL-8123/portfolio-with-agent.git
   cd portfolio-with-agent
   ```

2. **Create and activate a virtual environment**:
   ```bash
   # Windows (PowerShell)
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1

   # Windows (Command Prompt)
   python -m venv .venv
   .\.venv\Scripts\activate.bat

   # Linux / macOS
   python3 -m venv .venv
   source .venv/bin/activate
   ```

3. **Install dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

4. **Set up environment variables**:
   ```bash
   # Windows (PowerShell)
   Copy-Item .env.example .env

   # Windows (Command Prompt)
   copy .env.example .env

   # Linux / macOS
   cp .env.example .env
   ```
   *(Optional)* Configure custom database settings or email credentials in `.env`. By default, the application runs seamlessly using local SQLite (`database/portfolio.db`).

5. **Start the Flask development server**:
   ```bash
   python app.py
   ```

6. **View in your browser**:
   Navigate to [http://localhost:5000](http://localhost:5000) (or fallback port `5001`).
